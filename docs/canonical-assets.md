# Canonical models and private history

The public working tree contains one selected model pair per catalogue identity. `project/canonical-assets.json` records exact paths, hashes and roles. Gallery generation exposes only that selection; it must not revive a previous iteration.

All 14 engineering ships remain canonical in this repository, including Blend sources, GLB exports, animation rigs and their comparison gallery. Construction stages, PS7C construction animation, HUD sprite source scenes, Pyro sources and SciTek information/wireframe/highlight derivatives are functional deliverables of the selected asset, not historical competing versions.

Historical model payloads and their previews live in the private repository [openfa-assets-archive](https://github.com/ender-dev-pl/openfa-assets-archive). Its local `gallery/index.html` is a separate searchable gallery. The archive retains editable source bytes and exports, source Git blob identifiers, SHA-256 checksums, authoring records, shared procedural material inputs and tooling. Licenses remain unchanged. It is not deployed as public Pages.

## Replacing a model

1. Verify the new editable source and independent GLB runtime following the remastering workflow.
2. Preserve the outgoing committed model, its associated previews, source-specific metadata and required dependencies in the private archive. Run its `tools/verify_archive.py`; push a signed archive commit before retiring any public working-tree file.
3. Update the selected inventory study, canonical selection paths/hashes, source layout and archive provenance. Keep one selected study in the main catalogue. Retain functional animations and technical derivatives explicitly by role.
4. Rebuild the main gallery and verify the canonical boundary, source evidence, local links and browser behavior. Update gallery renders only after real runtime validation.

Historical generators may depend on retired source checkpoints. Run such a historical workflow in an ignored authoring workspace assembled with the required sources from the matching archive commit; do not restore those old models to the public source tree or canonical gallery. The archive preserves the original layout and source registries for this purpose.

The public main is published as a signed parentless snapshot. Prior source history is preserved in the private archive under history/2026-11-12/. GitHub-managed pull-request references and caches are separate from ordinary branch/tag refs.

## Runtime evidence boundary

Current payloads, render pixels and runtime reports remain hash-verified locally. Historical authoring inputs that were listed in an old runtime evidence bundle are now explicitly recorded as `archived_inputs`, with their unchanged original digest, Git blob and immutable archive commit. Public verification checks their provenance declaration against the transfer ledger; it does not claim to reread private bytes. The private archive verifier checks the actual historical bytes. These declarations never substitute for current native/GLB payload or render validation.

For three source-bound Achaean animation validators, the original implementation files remain unchanged for hash verification. Separate `archive_aware_*` adapters perform the same current geometry, animation, texture and render checks while accepting explicitly archived historical authoring inputs through `archive_evidence.verify_bound_input`. No model, render or original runtime report is regenerated by this transfer.

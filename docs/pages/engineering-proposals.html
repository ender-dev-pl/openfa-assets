Engineering ships versus the established small-craft fleet

Compare hull sections,wing profiles,structural divisions,materials and construction detail. Each image is fitted independently: this is a style comparison,not physical game scale. Canonical GLB references use the same review studio where available;other previews retain their existing cameras and lighting. Scout/research references are labelled separately.

Terran

Canonical-style pass:two reviewed cycles introduced a tapered layered deck,swept faceted gondolas,quiet red fields and canonical violet-grey/brass PBR targets. Actual complete Hull GLBs are compared in the same studio with construction layers omitted. Terraform retains its rotor;repair has six channels including independently closing jaws. Utility bodies remain broader than the combat wedge;user artistic acceptance is pending.

Rigellian

Canonical hidef alignment:second reviewed cycle adopts slate-jade,pale alloy,ochre and copper colours,with seated service lids,cooling louvres and protected tool covers. Corrected hidef Delphini and Lazzaro replace the older reference models in this same-studio comparison. Repair retains six animation channels with separate jaws. User artistic acceptance is pending.

Braccatian

Canonical-style pass:three reviewed cycles introduced rose-copper lobes and waist,pale ochre prow,narrow raised inlays and a surface-fitting repair strap. Five colour/ORM targets match current canonical atlas tiles;actual canonical GLBs are rendered in the same studio. Repair has a positioning yoke and independently closing fingers. Utility proportions remain distinct;user artistic acceptance is pending.

Mikotaj

Canonical-style pass:three reviewed cycles introduced slate-blue/gunmetal structure,dulled-gold accents,tapered rail profiles and slimmer faceted pods related to Ylikt-shan and Hiero. Gold and primary paint map medians match the canonical authored palette. Utility frames and tools remain functionally distinct;user artistic acceptance is pending.

Artemian

Canonical-style pass:two reviewed cycles introduced a pointed green deck,separated faceted silver fairings and canonical material medians. Current canonical GLB references are rendered in the same review studio. Repair has independent sliders,wrist and closing jaws;user artistic acceptance is pending.

Mauna

Canonical-style pass:Terraform used three actual attempts,Repair two (technical failures retained). Orthogonal slabs,stepped roofs,grey main bodies,blue-grey service insets and true recessed slots now follow the fleet. Five colour/ORM targets match canonical atlas tiles;actual GLB references use the same studio. Repair has five channels including independent jaws and a wrist. User artistic acceptance is pending.

Achaean

Canonical-style pass:two reviewed cycles introduced a pointed copper forebody,continuous crimson fields following the full mirrored silver-wing spline,and four canonical colour/ORM targets. Actual canonical GLBs use the same review studio. Repair has support,wrist and independent claws (four channels);mirrored wing surfaces are verified despite benign imported corner splits. User artistic acceptance is pending.

Authoritative terran:solar-matrix for gameplay, construction catalogue and Sci-Tek27. Package model.glb once and alias consumers. SolarMatrixRoot unit scale; use open default pose and disable CatalogueTurn in gameplay. PanelsClose/PanelsOpen are optional user-authorized extensions, with a near-closed truncated pyramid.

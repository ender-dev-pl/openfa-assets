# Messier-Lukannon

Canonical mobile Rigellian hull, issue #232. Use model.glb for all game presentations; model.blend is the editable source.

The supplied hi-def reference and original paletted RI2C.256 constrain the visible form. Hidden service structures, panel layouts and wear are authored. Broad formed skins replace the rejected dense regular panel grid. IS0C is the craft-quality benchmark, not a Rigellian design template.

Proposed size: 96 world units, native maximum extent 9.6. The client currently falls back to 96 for this id; integration must apply and verify the intended override. Root scale is identity, forward -Y, up Z in Blender; standard glTF axis conversion is applied. Windows/service details use the same authoring scale across the fleet.

One shared 2048-square worn PBR atlas, embedded in each portable GLB. runtime-verification.json binds native reopening, independent import, geometry and rendered evidence to hashes. No calibrated weapon sockets, flight behaviour or client GPU acceptance is claimed. The shared fleet comparison uses actual relative model sizes and a single camera.

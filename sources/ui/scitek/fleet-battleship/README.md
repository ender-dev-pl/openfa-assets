# Sci-Tek Fleet Battleship (research 09)

Preserves all 35 meshes, local transforms, vertices/faces, UVs and material slots of the existing Terran Fleet Battleship, including original wear and packed maps. The source model is unchanged. Actual ST09 palette-bound sprite and colour film plus all nine information caption anchors establish this research presentation. The three information phases are rear thruster (29..139), wingtip directional thrusters (170..280), and communications antenna/electric field sensor (311..421).

Ten new presentation meshes add the source-observed lower field sensor with diagonal mount, housing, projecting probe/bulb and wear seams, plus two extended wingtip housings with small wear marks. They supplement the existing interpreted model and do not alter its source. Sensor position/hidden construction and housing profiles remain authored approximations. New parts use grime/grain and readable wear; old surfaces are preserved.

The output includes 144x160 logical tile, 4x and disabled tile, 60-frame colour rotation, complete 423-frame information movie and animated Blend/GLB, whole technical wireframe and three static highlight GLBs. Approximately 80% visual correspondence is the user acceptance criterion. Existing smooth spine, broad continuous markings and simplified panel construction remain explicit deferred artistic gaps. Wire topology, camera poses and zoom interpolation approximate observed source phases. No extra operating effects or independent articulation are invented.

For information playback use information-timeline.json per-frame root/camera transforms and ortho_scale. Apply highlight_component to technical material hue and caption_component to text independently; use step hue changes. GLB alone does not portably retain animated material colour or orthographic scale. Saved information Blend contains those native animations. Static highlight GLBs bake the selected pose; hidden solid meshes must stay hidden in technical mode.

Build in Blender with build_battleship.py -- OUTPUT BASE_FLEET_BATTLESHIP_BLEND (geometry.py alongside). Copy material-clock.json to OUTPUT, then animate_information.py -- OUTPUT/fleet-battleship.blend INFORMATION_OUTPUT. render_preview.py renders all sixty colour poses. verify_native_import.py -- OUTPUT BASE_FLEET_BATTLESHIP_BLEND verifies preservation of the original 35 meshes, UVs, material slots and local transforms, independent solid import and root rotation, and source reload. export_highlights.py -- OUTPUT INFORMATION_OUTPUT bakes the three poses. verify_static_import.py -- OUTPUT INFORMATION_OUTPUT exports the unlit whole wireframe and independently renders four static technical imports. verify_information.py INFORMATION_OUTPUT SOURCE_DIRECTORY checks all 423 frames, source hue/caption metadata, zoom and eleven import samples. verify_rasters.py OUTPUT records native/import projected differences with a two-pixel tolerance at 640px for technical-line antialiasing. Packed-map export may need permission to write temporary images.

Binding research/09 and media paths are published in gallery/media/ui/scitek/integration.json. Blender runtime and independent imports are checked here; main game thread handles actual client/GPU integration acceptance. Private original pixels are evidence only and are absent from authored textures.

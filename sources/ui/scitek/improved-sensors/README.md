# Improved Sensors — Sci-Tek #208, legacy index 12

Dedicated research-display device based on actual ST12.256, all colour-preview phases and the three information-caption start/mid/end views. This research installs integrated underground sensors in colonies and future CPUs; it is not a new colony Sensor Array building. The arched beige casing, lower cabinet, sloping collector with four red traces, two pale lateral coils and upper calibration bars/dots follow the inspected source. Materials include procedural wear, dark seams and faded lower markings. No original pixels are used as model textures.

The solid Blend/GLB root is `SensorsRotor`, Z up, constant scale `[1.035,1,1]`. It carries a 60-frame, 15 fps negative-Z preview turn. Native tile is 144×160, registered without stretching into the recovered (14,8)..(127,151) source box. `tile-4x.png` preserves that registration at 576×640; `solid.png` is a separate studio framing. Disabled tile preserves native alpha. Green wireframe and three red-component GLBs have 896×896 closeups and 224×224 derivatives. Roles: chassis, data-collector, shielding-coils, calibration-indicators. Wire tessellation is an authored presentation grid; it does not imply recovered hidden hardware.

Information animation: 423 frames at 15 fps, with collector selected at frames29..139, coils170..280, calibration311..421 (zero based). The full sequence includes rotation, three closeups and returns. Caption ownership and intervals come from legacy; 3D poses, camera transforms and interpolation are authored interpretations, not recovered original transforms. Use the explicit per-frame timeline rotation, camera, orthographic scale and component hue. Keep root scale. Material hue and orthographic scale are not portable glTF animation channels, so GLB animation alone is insufficient. The technical camera can crop the surrounding chassis while retaining the selected subject, as in source closeups.

Bind `scitek:improved-sensors` to `openfa:presentation/profile/research/12`. Paths and gallery views are in `gallery/media/ui/scitek/integration.json`. Static native/import renders cover all five variants; additional imported solid poses cover three quarter turns. Closed geometry, pale normal indicators and component counts are checked. Full-information independent imports cover endpoints and all three closeups; reopening the saved Blend reproduces the native closeup. Both movies are fully decoded during verification. Game integration and runtime acceptance remain pending in the main thread.

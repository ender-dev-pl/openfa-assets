# Sci-Tek Photon Turret (research18)

Research presentation based on actual paletted PB18 static/colour frames and all nine ST18 caption anchors. Six selected existing PB18 refined meshes retain geometry, UVs and material slots: foundation joint, azimuth flange and four receiver-hatch parts. The existing building source remains unchanged. New geometry supplies the rounded pink elastoplastic armour, fixed weapon cup, gold egg-shaped strengthened barrel, tapered short nozzle, dark bore and thin indicator. New surfaces carry joint/grain wear; existing surfaces are not retrofitted. Root Z scale1.15 adapts the research silhouette, and is part of the GLB/metadata contract.

The colour preview has60frames at15fps: ONLY PhotonWeaponAzimuth swivels. PhotonResearchRoot, the armour base and receiver stay stationary. The loop closes at Blender61; display1..60. solid-animation-timeline.json supplements GLB with absolute mesh transforms relative to Root, serialized row-major4x4 using Blender column-vector math/Z-up. Translation entries3/7/11. Replace bind transforms; preserve Root scale[1,1,1.15]. For bind-baked geometry use current*inverse(bind); transpose/reverse multiplication for row-vector consumers. Do not replace this with a whole-building turntable.

The423-frame technical sequence highlights strengthened-photon-barrel (caption29..139), elastoplastic-fixed-base (170..280), and armoured-tracking-receiver (311..421). The closeup receiver pose aligns the actual hatch normal with the viewing direction. Technical wire groups are baked from the starting solid pose and animate separately through PhotonResearchRoot/camera. Do not apply solid head-swivel transforms to information wires. Use information-timeline.json for explicit root/camera, ortho_scale, highlight_component and caption_component; hue and orthographic scale are not portable GLB animation channels. Step material changes are independent of caption visibility.

Approximately80% visual correspondence is the requested criterion. Barrel/body profiles, hidden structure, wear, wire tessellation, camera and interpolation are authored interpretations. No original3D or pixel fidelity claim is made. Portable PBR retains representative worn colours; procedural microtexture remains native. Static technical GLBs are unlit and highlight poses are baked.

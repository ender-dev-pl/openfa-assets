# Sci-Tek Asteroid Engines (research 04)

Existing PB22 central and peripheral orb meshes are reused; the original model remains unchanged. The research presentation has four generators in opposing pairs, a central gravitic reactor, dark navy spherical housings, narrow seams and red indicators, and a flared green mounting base. Newly authored parts have readable scuffs and joint wear. Native and independently imported GLB renders were reviewed against actual PB22/ST04 legacy frames.

Approximately 80% visual correspondence is the current acceptance criterion. Geometry, wire topology, camera, zoom and pose interpolation are authored approximations. This is not a claim of recovered original 3D geometry or pixel fidelity. The portable PBR GLB preserves base material colours; native procedural microtexture is not baked.

The solid preview turns through 60 frames at 15 fps. The complete information sequence has 425 frames and three phases: central reactor (caption 29..139), opposing generator pairs (170..280), and fixed base (311..421). Material activity and caption visibility are independent in material-clock.json. Source decoded phase boundaries are updates 0/65/132. The saved information Blend contains animated technical materials and camera. For GLB playback apply information-timeline.json per-frame root/camera transforms, orthographic scale, highlight_component and caption_component; hue and scale are not portable glTF animation channels. Use step hue transitions. Do not render hidden solid meshes in information mode.

Build: Blender --python build_asteroid_engines.py -- OUTPUT BASE_PB22_BLEND (geometry.py alongside). Copy material-clock.json to OUTPUT; then animate_information.py -- OUTPUT/asteroid-engines.blend INFORMATION_OUTPUT. render_preview.py renders all 60 solid frames. verify_native_import.py -- OUTPUT verifies four opposing generators, source reload and independent solid import in Blender. export_highlights.py -- OUTPUT INFORMATION_OUTPUT creates standalone highlight GLBs and renders. Model parts are named in model.json. Gallery media and integration.json supply tiles, disabled state, previews and binding research/04. Client/GPU integration remains for the main game thread.

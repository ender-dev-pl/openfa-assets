# Sci-Tek Gravity Nullifier (research 10)

Reuses the existing PB12 central orb mesh, preserving its geometry, UVs and local transform. Its copied finish is changed to source-observed dark navy; no new wear is retrofitted to that existing surface. The old source Blend and its other components remain unchanged. The dense old seam cage, full foundation drum and four regulator boxes are not used in the research presentation.

Actual paletted PB12 colour phases and all nine ST10 caption anchors show a sphere over a shaped mounting base with three large openings and four small cardinal sensors. Newly authored mounting ring, three spokes, hub/stem, two restrained shell joints, seam indicators and four domed orientation sensors follow those recognizable features. New parts have material-appropriate grain, grime and scuffs. The 94-mesh assembly is closed with positive volumes. Scoped ray probes verify three actual open sectors and the three supporting arms. The reused orb geometry/UV/local-transform signature is checked against the original source.

The phases are central gravitic reactor (caption 29..139), shaped base viewed from above (170..280), and a cardinal orientation sensor closeup (311..421). Colour preview rotates through sixty frames; full information animation has 423 frames, both at 15 fps. Material activity is independently sourced from caption visibility in material-clock.json. For information GLB playback apply information-timeline.json root/camera transforms, ortho_scale, highlight_component and caption_component separately, with step hue transitions. GLB alone does not portably retain animated hue/orthographic scale. Native information Blend contains those animations. Static highlight GLBs bake selected poses. Hidden solid meshes must remain hidden in technical mode.

Approximately 80% visual correspondence is the user acceptance criterion. Base openings/spoke profiles, hidden construction, exact sensor shape, wire topology and camera interpolation are authored approximations rather than recovered 3D geometry. The original texture pixels are reference-only and absent from authored maps. Procedural microtexture is native; portable PBR exports retain base material values and geometric wear.

Build with Blender: build_nullifier.py -- OUTPUT BASE_PB12_BLEND, with geometry.py alongside. Copy material-clock.json to OUTPUT, then animate_information.py -- OUTPUT/gravity-nullifier.blend INFORMATION_OUTPUT. render_preview.py renders all sixty colour poses. verify_native_import.py -- OUTPUT BASE_PB12_BLEND checks orb reuse, closed geometry, actual openings, cardinal sensor count, independent solid import/root animation and saved-source reload. export_highlights.py -- OUTPUT INFORMATION_OUTPUT creates baked-pose highlight GLBs. verify_static_import.py -- OUTPUT INFORMATION_OUTPUT exports whole unlit wireframe and independently renders four static technical variants. verify_information.py INFORMATION_OUTPUT SOURCE_DIRECTORY checks all 423 frames, source hue/caption metadata, zoom and eleven independent imports. verify_rasters.py OUTPUT records projected native/import differences with two-pixel tolerance at 640px for technical antialiasing.

Media paths and research/10 binding are in gallery/media/ui/scitek/integration.json. Blender runtime and independent imports are verified here; main game thread must integrate and check actual client/GPU output.

# Sci-Tek Missile Bay Extension

Dedicated presentation model for legacy research index14, based on the actual ST14.256 tile, the180-frame colour preview, all three caption-anchor studies and the423-frame technical film. It is a research assembly, not a new simulation building. Original pixels are private evidence and are not included as textures.

The fixed annular magazine, stored missile caps, tall mast, open flared upper guard, vertical hydraulic guides, split blast doors and side control cabinets follow the inspected imagery. Editable Blender metalwork has procedural wear, seams and dark recesses. Portable GLB retains explicit material colours and geometric seams/recesses; Blender procedural noise/bump is not baked into GLB textures. Mesh topology, hidden depths, exact linkage dimensions and camera transforms are interpreted. Twenty magazine positions and the simplified display-wire tessellation are authored reconstructions of the visible arrangement.

Solid preview:180 frames at15fps. The corrected cycle follows actual `_MA/ST14.VID`: the rocket rises from the right magazine outlet, traverses and inclines onto the feeder, enters the mast, then the overhead loader descends and returns. `MissileTransferPivot`, `MissileFeederCradle` and `HydraulicTransferCarriage` have separate ownership. The fixed housing does not turn. Dimensions and trajectories are authored interpretations at the requested approximately80% fidelity. The loop closes at Blender frame181; display frames1..180. Hidden reset occurs inside/below the housing. Do not replace the mechanism with a body turntable. Technical films and static technical groups remain separate and unchanged.

`solid-animation-timeline.json` supplements the authoritative GLB hierarchy with absolute mesh transforms relative to Root. Values are serialized row-major4x4, using Blender column-vector mathematics and Z-up (translation entries3,7,11). Replace bind transforms. For already bind-baked geometry the column-vector delta is current * inverse(bind); transpose and reverse multiplication for row-vector consumers. Preserve separate mesh ownership and convert coordinates once. Static hardware keeps its bind pose. `solid_preview_camera` records the actual authored preview framing.

Registered native144x160 and disabled tiles, and4x576x640 tile, contain the complete model in the measured occupied legacy box(22,0)..(122,160) without stretching. The source stalk touches the top crop; the model's closed cap is an interpretation. The transparent studio render is separate from registered tiles.

Information:423 frames at15fps, four wire groups including chassis. Highlight windows are revolving-storage-rack29..139, missile-loading-assembly170..280 and targeting-control311..421. Closeups show the magazine from above, the hydraulic/door assembly from the front, and the side controls. Technical wires are baked from the starting pose and use a separate Root/camera clip. Apply explicit information-timeline.json camera, XYZ rotation, orthographic scale and component hue; glTF alone does not portably animate hue/orthographic scale. Initial information Root yaw30 degrees must be replaced when evaluating timeline poses. Keep solid and information timelines separate.

Bind `scitek:missile-bay-extension` / `openfa:presentation/profile/research/14`. Paths and variants are registered in gallery/media/ui/scitek/integration.json. Source-bound verification covers closed hardware, missile count, fixed body, local motion and loop closure, independent GLB samples, static variants, saved-source reload, three legacy-framing comparisons and full movie decoding. Actual game integration/runtime acceptance belongs to the main thread.

Build in Blender: `-b -t 4 --python-exit-code 1 --python build_missile_bay.py -- OUTPUT`. Run render_preview.py and animate_information.py with INPUT_BLEND and OUTPUT. `--keyframes-only` is a review subset, not delivery. Run geometry/articulation/information-state checks in Blender and device/raster/information/framing checks in Python/Pillow/FFmpeg. Raster checks expect sibling bay-preview-poses-ready. Information checks require saved-source frame88 named reload-0088.png. Framing checks take the private original-codec ST14 directory; keep these original pixels private. Outputs belong outside sources.

Rebuild the corrected solid delivery by first running build_missile_bay.py into a baseline directory, then refine_feed_cycle.py with that baseline Blend and a separate corrected output directory. Render the corrected Blend using render_preview.py and render_solid_reload.py. The refinement preserves mesh vertex/face data and adds the separate feeder parent. verify_articulation.py checks magazine rise, lateral transfer and inclination, mast insertion, loader delay/descent, feeder return, fixed housing, loop closure and13 independent GLB poses. Geometry proofs for the original assembly retain their original source hashes; feed-cycle-provenance.json connects the corrected solid source to the unchanged meshes.

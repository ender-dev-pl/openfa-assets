## Independent source material and caption clocks

The corrected information presentation uses material-clock.json rather than treating text visibility as red selection. The source has no visible red at frames 187 and 268 during the control phase; this may be occlusion/projection rather than an internal material toggle. This authored adaptation follows observed screen red activity with explicit hue states and does not claim recovered internal source material behaviour. All 423 source red activity states match: 334 red frames and 333 caption-visible frames. Lead-in flashes, green interruptions during captions and the final red capacitor hold are retained. Caption timing remains 29..139, 170..280 and 311..421; these intervals do not define the highlight state.

Source-reviewed component transitions are decoded updates 0, 65 and 130 (timeline frames 0, 141 and 282). Source images at the adjacent red states verify energy-output, pulse-control and capacitor-system identity; hashes and provenance are recorded in the clock file. The original-clock audit measures only red presence, so this separate semantic boundary review is required.

The client must consume highlight_component for material hue and caption_component for text visibility independently. Use step transitions for hue; do not interpolate the red/green state. Every saved-scene frame and half-frame flash transition was checked. Full renders were compared with the source on/off clock at all 423 frames; 21 independent GLB samples cover every previous mismatch and the original closeup anchors. Camera/geometry remain authored approximations.

The information WebM uses VP9 Profile 1 lossless RGB (gbrp): all decoded RGB frames match native renders exactly. Lossless RGB avoids chroma-subsampling artifacts on tiny coloured lines.

All four exported information materials explicitly declare KHR_materials_unlit. Apply timeline hue to unlit technical lines; a black PBR base plus emission does not preserve the native edge response of tiny red fragments. Independent import checks reconstruct the same pure emission graph as the native scene.

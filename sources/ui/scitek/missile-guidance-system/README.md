# Sci-Tek Missile Guidance System

Dedicated research presentation for legacy ST15 / research15. The actual144x160 tile,60-frame colour rotation, all three exact caption-anchor studies and423-frame information film establish the assembly: violet translucent holographic sphere, arched metal I/O strap with round aperture, broad interface belt, data slot/status indicators and pointed/arched lower computer armour. Original pixels are private evidence, not textures.

The full sphere and six subtle violet inner-core region materials interpret the source's mottled holographic display; no original map/coastline topology was recovered. The true through-hole is boolean-cut through the curved strap. Both front and rear armour skirts end in a point, as seen at source updates0 and30; raised side boundaries produce the arch at quarter turns. Hidden joins are reconstructed, not recovered mesh data. Forty small explicit wear/scuff meshes survive GLB; procedural abrasion adds detail in Blender but is not baked to portable textures.

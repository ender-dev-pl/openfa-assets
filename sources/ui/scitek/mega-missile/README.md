# Sci-Tek Mega Missile (research 13)

Preserves all 64 meshes, vertices/faces, UVs, material slots, local transforms and finish of the existing PM09 Mega Missile. The old source remains unchanged. Actual paletted PM09 colour phases and all nine ST13 caption anchors establish the three information subjects: four multi-directional thrusters (caption 29..139), manoeuvring fins (170..280), and nose navigation/guidance systems (311..421).

The original study's hidden threefold vane/armour layout remains an interpretation; it is preserved. Four new seated thrust lobes and four small wear seams provide the explicit four-thruster presentation missing from that study. New parts have material-appropriate procedural grain/grime and geometric wear. Chamber shape/hidden attachment geometry remain authored approximations. Four scoped shared-interior witnesses verify attachment to the existing pressure casing; all eight added meshes are closed with positive volume.

The solid mode retains the existing lower armour/casing/nozzle. Technical curves omit those interpreted lower components in favour of the four source-described thrust lobes, so their old wire cages do not obscure the research subject. Use the authored technical GLBs rather than deriving this presentation from every solid mesh. Nose cone/tip/pin and the preserved vanes/ribs/rails form the other two highlight groups. No independent fin deployment or thrust effect is invented.

Outputs include 80x160 logical tile with its actual original occupied rectangle, 4x and disabled variants, sixty-frame colour rotation, whole unlit wireframe and three baked-pose highlight GLBs, and full 423-frame information WebM/Blend/GLB. Both movies run at 15 fps. Approximately 80% visual correspondence is the user acceptance criterion; original panel/vane proportions, inferred hidden layout, new chamber profiles, wire topology and camera interpolation remain explicit approximations. Original pixels are reference-only.

For information playback consume information-timeline.json: replace root/camera transforms, apply ortho_scale, highlight_component and caption_component independently. Use step material hue transitions. GLB alone does not portably retain animated colour/orthographic scale; native information Blend contains these animations. Static highlight GLBs bake the selected root pose. Hide solid meshes in technical mode.

Build in Blender: build_mega.py -- OUTPUT BASE_MEGA_BLEND, geometry.py alongside. Copy material-clock.json into OUTPUT and run animate_information.py -- OUTPUT/mega-missile.blend INFORMATION_OUTPUT. render_preview.py renders all sixty colour poses. verify_native_import.py -- OUTPUT BASE_MEGA_BLEND checks preservation of all 64 source meshes and independent 72-mesh solid import/root rotation/reload. verify_research_additions.py -- OUTPUT checks eight closed positive additions, four opposite thrust chambers and their shared casing witnesses. export_highlights.py -- OUTPUT INFORMATION_OUTPUT bakes the three static technical variants. verify_static_import.py -- OUTPUT INFORMATION_OUTPUT exports whole unlit wireframe and independently renders four static imports. verify_information.py INFORMATION_OUTPUT SOURCE_DIRECTORY checks all 423 frames, independent source hue/caption metadata, zoom and eleven import samples. verify_rasters.py OUTPUT records projected differences with two-pixel tolerance at 640px for technical antialiasing. Procedural microtexture is native; portable PBR retains base colour and geometric wear.

Binding research/13 and media paths are in gallery/media/ui/scitek/integration.json. Blender runtime/import checks are supplied here; main game thread handles actual client/GPU integration acceptance.

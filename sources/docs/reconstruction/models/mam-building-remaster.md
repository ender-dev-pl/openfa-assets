# Mikotaj, Artemian and Mauna building remaster programme

Tracking: [programme #258](https://github.com/ender-dev-pl/openfa-assets/issues/258), [Mikotaj #259](https://github.com/ender-dev-pl/openfa-assets/issues/259), [Artemian #260](https://github.com/ender-dev-pl/openfa-assets/issues/260), [Mauna #261](https://github.com/ender-dev-pl/openfa-assets/issues/261). Related: #9 and #7 in this asset repository.

The scope is 65 canonical building identities: 21 Mikotaj, 23 Artemian and 21 Mauna, in that order. The immutable input baseline records all 72 existing source/export pairs without copying them. They are preserved until the complete model-refinement programme finishes. Archival-repository migration and canonical-only history rewriting are deferred by the maintainer; this programme does neither.

Follow [the remaster workflow](../../../../docs/remastering-legacy-objects.md): inspect actual paletted surface, enlargement and technical/catalogue references plus relevant _MA archive/video families and original function/culture text; produce an actual ImageGen concept (up to three attempts), reviewing discrepancies against legacy; author one coherent canonical Blend/GLB for gameplay/build/SciTek; add appropriate wear; derive technical views from the same geometry; measure export budgets; actually reopen/import/render and visually compare GLB to concept and legacy; update both galleries, sign the milestone and hand it to the authorized game thread. No numerical 80-percent score or client acceptance is inferred from technical tests.

## Initial evidence and progress

No model delivery is complete in this baseline milestone. MK01 Base Crystal has a selected real ImageGen concept and source-specific review, with model/runtime/gallery gates pending. The original 41-update catalogue sequence is a holographic reconstruction, not a turntable or an independently moving mechanism. _MA contains PB/PH/PM/PS/ST families and archive stills; a direct MK01 string match was not found, which does not replace the required semantic subject-binding review.

The existing generic MK01 recipe's sharp crystal cluster is not treated as ground truth. Original paletted views show a heavy rounded mineral-metal mass, joined upper lobes, central blue emitter and two brass lower bands. The mining architecture lore and object function determine the interpretation; exact alloy chemistry and hidden construction remain unknown.

Private decoded legacy pixels and authoring logs remain outside published sources. Use the main worktree; no extra checkout, game build or copied archive. Task disk accounting, recoverable checkpoint and original image inputs are retained privately in the game repository's ignored artifacts.

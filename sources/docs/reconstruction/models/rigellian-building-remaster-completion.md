## Fidelity, mechanisms and limits

Actual palette-matched surface layers, catalogue reveal/highlight and outlined technical phases were reviewed. The fresh audit decoded the original archive and VID data read-only and matched saved reference pixels for all23buildings. It does not assume that Terran ST animations are Rigellian mechanism evidence. Hidden geometry, exact dimensions and several mechanism details remain authored interpretation; feedback records significant concept deviations rather than treating generated art as authority.

One canonical skeleton supplies gameplay, build menus, SciTek and derived technical views. RI10 uses its shared-mesh cycle and STEP descriptor lookup; RI18 retains supported split-dome clips. RI11 has a permanent open port with no invented lid animation. RI19/RI22/RI23 expose manual yaw assemblies. Catalogue reveal is distinct from camera rotation. Shared construction assets remain separate.

The current native/imported proof binds287renders; fresh comparison covers139pairs. Maximum foreground-channel mean difference is below0.458/255 and maximum threshold-silhouette disagreement fraction below0.000018. These demonstrate export agreement, not a numerical percentage of legacy likeness. Source-preservation tests, conceptual feedback and actual visual review provide the separate fidelity evidence.

Client scale/placement/damage/state mapping, uncalibrated yaw phase/sign, descriptor17 shadow/lower-structure composition where documented, continuous volumetric collision freedom, complete missile/ship clearance and Android frame rate remain outside this asset-delivery claim. No final user artistic acceptance is asserted. Historical studies stay preserved but must not be packaged as additional current variants.

## Validation and disk care

Local validation includes current project/layout, source-bound runtime evidence, licensing,16runtime-evidence regressions, actual Blender material/UV/mechanism tests from model milestones, gallery animation/showcase/filter tests, changed-file publication checks and required Verify-ChangedCodeQuality.ps1. Asset Blender runtime was exercised; no game build was created. Per-model signed commits and English technical issue comments were read back, and main-thread delivery receipts confirmed.

The existing checkout was reused. Final audit removed only its own encoded frame PNGs6,259,957bytes and temporary decoder dependency59,964,804bytes after successful verification. Existing models and historical evidence were not deleted. No new checkout, archive or D:move was used.

Mobile-ship programme [#248](https://github.com/ender-dev-pl/openfa-assets/issues/248) remains unfinished and outside this completed building scope.

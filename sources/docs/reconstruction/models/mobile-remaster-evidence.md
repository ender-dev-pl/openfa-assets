# Published mobile remaster evidence

`mobile-remaster-runtime-v1` binds existing accepted inventory gates to the exact bytes reviewed in Blender. It records the canonical Blend and GLB, model metadata, runtime report, recipe and baseline when present, source tools, visual review report, and native/imported render pixels. Source files retain their actual line endings; this format does not normalize hashes.

The four culture registration tools call `bind_record` after their family-specific checks. Binding never promotes a gate. `verify_project.py` checks published non-Terran mobile gates without requiring private legacy media. The original runtime evidence format remains supported.

Run `python tools/test_mobile_remaster_evidence.py` for positive and rejection cases, then the relevant culture test and `python tools/verify_project.py`. Re-run the actual Blender validation whenever reviewed binary, recipe or authoring/verifier inputs change; editing evidence hashes is not validation.

These reports establish agent source/runtime review only. Final user artistic acceptance, client integration, gameplay scale and mount calibration remain separate. Family-specific tests retain responsibility for concept, material and geometry criteria beyond this common bundle.

# RI01 Central Unit preservation delivery

Tracking: openfa-assets #253, PR #254. This milestone preserves the assessed CPU rather than redesigning it.

## Evidence and concept feedback

Actual paletted RI01 surface ground0 and complete body1 plus catalogue phases0/10/20/30/40 were inspected. The catalogue is a reveal and red-highlight presentation of a fixed view, not a rotation or recovered operational cycle. Function record901 identifies the first colony building supplying essential resources until dedicated facilities exist. CDB record18 describes ergonomic, elegant Rigellian architecture and pervasive research facilities; it does not define hidden machinery. Source text/pixel hashes are in visual-review.json; original pixels remain private.

Two actual built-in ImageGen requests were used, below the three-request maximum. Attempt1 invented a large central roof opening and a crescent side cutout and was rejected. Attempt2 corrects these to solid crown seating and a small round offset well. Its broad saucer, waisted base, three-prong crown and green/brass palette broadly agree. Grille subdivision, neck proportions, fitting sizes and the precise finish remain interpretation. Exact prompts and both outputs are retained. Concept deviations do not override the assessed model.

## Preserved model

Canonical files: `sources/objects/rigellian/central-unit/model.blend` and `model.glb`. All75evaluated components and40,636triangles are protected without reduction. Seven materials, two embedded maps and existing finishes are retained. The clean CPU body predates the new-object wear instruction and is exempt from retrospective wear; existing crown finish is preserved too. Earlier studies remain historical evidence, not additional runtime payloads. Technical wireframes derive from the same current geometry.

Source SHA256: `488485fa840b3599c104bbcfc1872c4b8410688adee9f1d4dc7a5a3592295ac3`, the latest refined RI01 source. Checks retain the repaired cut roof well, sleeve/floor/saucer and cooling-fin contacts, crown socket/rim clearance, roof-following service cap, open neck grille, broad tapered side crown arms and one sampled contact component. Contact sampling is not exhaustive solid-intersection proof.

Saved-native and independent-import validation checks closed positive meshes, component/material identities, protected evaluated surfaces, used UV corner projections, decoded map channels and scalar material properties. Scalar shader values are compared at8-bit quantization; this is not exact floating-point shader identity. Imported glTF channel packing and scalar multiplication are evaluated rather than requiring identical Blender node layouts. Nine actual renders cover source, saved native and imported GLB at three corresponding angles. Render execution uses two CPU threads and CPU denoising after an OpenImageDenoise memory failure; model geometry is unchanged.

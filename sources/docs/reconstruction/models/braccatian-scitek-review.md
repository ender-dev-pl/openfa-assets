# Braccatian Sci-Tek reference applicability (#190)

The current presentation catalogue was resolved for all 36 research subjects:
`informationAnimationId` -> animation -> asset -> `_SCITEK/STxx.VID`, and
catalogue normal preview -> `_MA` archive entry. None of the 36 preview entries
begins with `BR`. They are PB/PH/PM examples or separate ST technology objects.
This establishes the actual bindings, rather than assuming that a similarly
named technology contains a Braccatian wireframe.

`braccatian-scitek-evidence.json` binds the current catalogue, original videos,
original executable/codec, timeline decoder, cache metadata and all decoded PNG
files. The existing private original-codec decode cache from the Rigellian
audit was reused; this is **not a fresh decode**. All input hashes were checked
against the current original installation. Each original container was parsed
again and compared chunk-for-chunk with the cached metadata, including final
Stop chunks and all held Same frames. The 36 films have 7,282 decoded image
updates across 15,794 timeline frames. Same frames preserve the preceding
image; they do not add another unique decoded image. Variable film lengths
are retained, including ST04, ST05, ST07 and ST21.

All 36 eighteen-phase motion contact sheets were visually inspected in six
private overview sheets (648 sampled updates, including each film's first and
last decoded image). This is a sampled motion review, not a claim to have
visually inspected all 7,282 image updates. Views include whole objects,
changed viewing angles, enlarged details and red-highlighted components in
green wireframes. They are animated technical presentations; whole-object
rotation/zoom or red emphasis does not establish a gameplay operating clip.
No sampled diagram establishes the Braccatian handbell casings, Longhouse
complex, storage jar or other race-specific body construction.

The films remain useful functional and construction context where they depict
the actual subject (for example the earlier Terran seismic-penetrator work).
For this race, the correctly paletted BR surface parts, all populated headings
and observed states remain the primary geometric evidence. CDB and functional
narratives constrain interpretation. No Sci-Tek-derived Braccatian operating
animation is introduced on the basis of this review. Existing authored launch
motion remains subject to its own source and clearance checks.

Original videos, frame pixels and viewing sheets remain private in ignored
artifacts. Only hashes, binding identities, observed applicability and review
limits are published. This review satisfies the current Sci-Tek applicability
audit; it does not complete remaining per-model refining or retention decisions.
